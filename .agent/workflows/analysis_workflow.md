# Analysis Workflow

## When to use
Use for decomposition-heavy tasks: diagnosing causes, comparing options, evaluating trade-offs, or framing decisions.

## Inputs
- Problem statement and decision objective
- Constraints, assumptions, and evaluation criteria
- Data or evidence set to analyze

## Sequence
1. Frame the decision/problem boundaries.
2. Decompose into hypotheses or candidate options.
3. Evaluate each against criteria using available evidence.
4. Synthesize trade-offs and rank recommendations.
5. Record rationale, assumptions, and risk sensitivities.

## Outputs
- Decision-ready analysis with explicit rationale
- Ranked options or root-cause conclusions
- Risk register and follow-up checks

## Failure conditions
- Criteria are missing or mutually inconsistent.
- Evidence is insufficient to discriminate options.
- Analysis cannot be reproduced from documented logic.

## Handoff
Deliver recommendation, supporting rationale, confidence level, and what new evidence would change the conclusion.
