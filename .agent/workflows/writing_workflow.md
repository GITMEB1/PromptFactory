# Writing Workflow

## When to use
Use for tasks where primary output is written content quality: clarity, structure, audience fit, and consistency.

## Inputs
- Writing objective and target audience
- Required claims, references, and constraints
- Style/tone expectations

## Sequence
1. Define audience, purpose, and success criteria.
2. Build an outline with section-level intent.
3. Draft content prioritizing factual correctness and flow.
4. Edit for concision, coherence, and terminology consistency.
5. Run final pass for references, formatting, and completeness.

## Outputs
- Publication-ready draft (or revision) aligned to audience and goals
- Change summary highlighting major editorial decisions

## Failure conditions
- Objective or audience remains undefined.
- Required evidence for key claims is missing.
- Style constraints conflict with non-negotiable content requirements.

## Handoff
Provide final draft, unresolved editorial questions, and explicit asks for reviewer feedback.
