# Practitioner Source Index

Practitioner sources are domain-experienced, non-official materials (e.g., experts, operators, maintainers, consultants, and technical communities).

## Criteria
- Author has demonstrated domain-relevant track record and identity continuity.
- Claims are specific, testable, and contextualized (environment/version/date).
- Source includes evidence (benchmarks, code, postmortem details, datasets, or reproducible steps).
- Independent corroboration is available for consequential claims.

## Allowed Usage
- Fill operational gaps not covered in official docs (implementation pitfalls, tuning heuristics).
- Provide practical trade-off framing and field-tested patterns.
- Generate hypotheses to validate against official/retrieval sources.
- Support medium-risk guidance when credibility threshold is met.

## Failure Modes
- **Anecdotal overreach**: isolated experience presented as universal truth.
- **Undisclosed incentives**: sponsorship/affiliation biases recommendations.
- **Reproducibility failure**: missing setup details or unverifiable benchmarks.
- **Cargo-cult propagation**: copied advice detached from underlying constraints.
