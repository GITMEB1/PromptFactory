# Prompt Factory v2

Prompt Factory v2 is a **context-and-evidence operating system** for disciplined prompt workflows.

It is designed to help an LLM or human operator:
- choose the right source class for a task
- factor in freshness and live research when needed
- separate official facts from practitioner insight
- preserve private context without over-trusting it
- build grounded claims before final composition
- evaluate outputs and capture lessons

## Core workflow

**Task Intake → Freshness Check → Source Routing → Retrieval / Reading → Credibility Grading → Claim Inventory → Response Plan → Composition → Lint / Eval → Lessons**

## Source classes

1. Official
2. Practitioner
3. Private Context
4. Live Retrieval
5. Model Prior
