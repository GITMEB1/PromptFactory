# Prompt Factory v2

Prompt Factory v2 is a documentation-first operating system for producing reliable, auditable LLM outputs by standardizing how teams intake tasks, route sources, build evidence-backed claims, compose responses, and log outcomes across lightweight and deep execution modes.

## Canonical execution chain

**Task Intake → Freshness Check → Source Routing → Retrieval / Reading → Credibility Grading → Claim Inventory → Response Plan → Composition → Lint / Eval → Lessons**
